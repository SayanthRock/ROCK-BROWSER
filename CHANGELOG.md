# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-05-18
### Added
- Initial release of ROCK BROWSER.
- Basic web browsing functionality with WebView.
- Multi-tab support.
- Settings screen for managing preferences.
- Optional GitHub integration (Authentication, Profile viewing).
- Bookmarks and History management.
- Download management.
- Privacy controls (clear data, incognito mode).
- Material 3 Compose UI with Dark/Light theme support.
