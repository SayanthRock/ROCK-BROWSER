# Security Policy

## Supported Versions

The following versions of ROCK BROWSER are currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within ROCK BROWSER, please do not disclose it publicly. Instead, send an email to the security team at security@sayanthrock.com. We will respond as quickly as possible.

We take security issues very seriously and will work with you to resolve the vulnerability promptly.

## Security Practices
- OAuth tokens are encrypted using the Android Keystore system.
- Network traffic uses HTTPS by default.
- WebView configurations prioritize security (e.g., restricted file access).
